# MCR Archive

A mobile-first, dark-mode My Chemical Romance fan archive, prepared as a static Progressive Web App (PWA) for public deployment on Vercel.

## Included

- Studio album catalogue and selected additional releases
- Special **Black Parade Tour 2025 Setlist** with the 20 tracks in the supplied screenshot's order
- Song search and saved-song bookmarks
- Song pages with a field for user-provided lyric text
- Local lyric saving for offline reading
- Service worker and installable PWA manifest
- Vercel static hosting configuration

## Deploy

See [DEPLOY.md](DEPLOY.md) for GitHub and Vercel instructions. No build step, database, environment variables, or framework installation is required.

## Important notes

- This is an unofficial fan project and is not affiliated with My Chemical Romance.
- The project includes song titles, not complete copyrighted lyrics. Visitors can add text they have permission to use.
- Saved lyrics and bookmarks are local to the browser/device and do not sync across devices.
- A public Vercel deployment is accessible to anyone with its URL. Do not put private information in it.
